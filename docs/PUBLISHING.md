# 上架到 Chrome 線上應用程式商店

## 1. 準備

1. **註冊開發人員帳號**：<https://chrome.google.com/webstore/devconsole>
   - 用**家長自己的** Google 帳號登入（不要用孩子的帳號），帳號需開啟兩步驟驗證。
   - 同意開發人員協議，支付一次性註冊費 US$5。
   - 在「帳戶」頁面填寫發布者名稱、驗證聯絡用 email；「交易者聲明」個人免費發布選「非交易者」。
2. **打包**：`powershell -File scripts/package.ps1` → `dist/kids-safe-browsing-<版本>.zip`
3. **商店素材**（已產生在 `store/`）：

   | 素材 | 檔案 |
   | --- | --- |
   | 商店圖示 128×128 | `extension/icons/icon128.png` |
   | 螢幕截圖 1280×800 | `store/screenshot-1-whitelist.png`、`store/screenshot-2-visit-notify.png`、`store/screenshot-3-blocked.png` |
   | 小型宣傳圖 440×280 | `store/promo-small-440x280.png` |

4. **隱私權政策網址**：本 repo 是公開的，把 `PRIVACY.md` commit 並 push 到 GitHub 後，使用
   `https://github.com/vikhung/AllowWebsite/blob/main/PRIVACY.md`

## 1.5 在開發人員控制台建立項目

1. 點「新增項目」→ 上傳 `dist/kids-safe-browsing-<版本>.zip`。
2. 依序填寫左側各分頁（內容見下方第 2、3 節）：
   - **商店資訊**：說明、類別、語言（中文（台灣））、圖示、螢幕截圖、宣傳圖
   - **隱私權**：單一用途、權限理由、遠端程式碼、資料使用、隱私權政策網址
   - **發布**：瀏覽權限選 **「不公開」（Unlisted）**，只有拿到連結的人能安裝；之後可改成「公開」
3. 右上角「提交審查」。可勾選「審查通過後自動發布」。

## 2. 商店資訊（可直接複製）

- **名稱**：孩童安心上網管理平台
- **類別**：「家庭」（Family）；若清單中沒有，選「工具」（Tools）
- **語言**：中文（台灣）
- **簡短說明**：家長管理孩子上網：白名單封鎖、封鎖通知、網站瀏覽通知，設定透過 Chrome 同步到每台電腦。
- **詳細說明**：

```
孩童安心上網管理平台：讓家長輕鬆管理孩子在 Chrome 上的上網行為。兩項管理功能可分別啟用：

【管理功能 1：白名單管理】
★ 只允許您核可的網站（含其子網域），其他網站顯示友善的提示頁面
★ 封鎖頁快速放行：孩子需要某個網站時，家長在封鎖頁輸入密碼即可允許
★ 可暫停 15 分鐘或 1 小時，時間到自動恢復
★ 孩子開啟未允許的網站時，呼叫您指定的 API（Webhook、Telegram Bot 等）通知家長

【管理功能 2：網站瀏覽通知】
★ 不封鎖，孩子瀏覽網站時呼叫您指定的 API 通知家長
★ 適合先觀察孩子常去哪些網站，再建立白名單

【共同特色】
★ 家長密碼保護：孩子無法自行修改設定
★ 跨電腦自動同步：在公司電腦登入孩子的帳號完成設定，孩子在家用另一台電腦登入後自動套用
★ 開發者不收集任何資料：設定只存在您的 Google 帳號同步空間，通知只送到您指定的網址

使用方式：
1. 在孩子的 Chrome 登入孩子的 Google 帳號並開啟同步
2. 安裝本擴充功能，設定家長密碼，啟用需要的管理功能
3. 完成！孩子在其他電腦登入同一帳號時，設定會自動同步
```

## 3. 隱私權分頁（Privacy practices）填寫建議

**單一用途說明（Single purpose）**
> 家長控制：依家長設定管理兒童在 Chrome 中可瀏覽的網站（白名單封鎖），並可將兒童開啟的網站通知家長。

**權限理由（Permission justification）**

| 權限 | 理由 |
| --- | --- |
| `declarativeNetRequest` | 建立規則，將不在白名單中的網頁導向封鎖頁面，這是本擴充功能的核心功能。 |
| 主機權限 `<all_urls>` | 家長控制必須套用在所有網站上；導向（redirect）規則需要對應網站的主機權限。另外，選用的通知功能會把網址送到家長自行設定的 Webhook 網址，該網址由家長決定，因此需要可連線到任意網域。 |
| `tabs` | 家長修改白名單後，將已開啟且不再允許的分頁導向封鎖頁；彈出視窗顯示目前網站是否被允許；家長啟用「網站瀏覽通知」時，取得載入完成網頁的網址與標題，送到家長指定的 Webhook。 |
| `identity`、`identity.email` | 取得目前登入 Chrome 的帳號 email，只在家長啟用通知時放進通知內容，讓家長分辨是哪個孩子觸發；不會傳送給開發者。 |
| `storage` | 以 chrome.storage.sync 儲存白名單、通知設定與家長密碼雜湊，並同步到孩子登入的其他電腦。 |
| `alarms` | 家長暫停白名單封鎖後，在時間到時自動恢復。 |
| 遠端程式碼 | 否，未使用任何遠端程式碼。 |

**資料使用**：因為有通知功能，建議誠實勾選 **「網頁瀏覽記錄（Web history）」**，並在說明中寫明：
「僅在家長啟用通知時，將孩子開啟的網址傳送到家長自行指定的網址；開發者不會收到任何資料。」
另外因通知內容含登入帳號 email，也要勾選 **「個人識別資訊（Personally identifiable information）」**，說明同上。
其餘類型勾選不收集；勾選三項聲明（不出售、不用於無關用途、不用於信用評估）。

## 4. 審查注意事項

- `<all_urls>` 屬於廣泛主機權限，審查時間通常較長（數天到數週），說明文字要清楚寫出「家長控制」用途。
- 每次更新記得調高 `manifest.json` 的 `version`。
- 上架後取得的擴充功能 ID，填入 `policies/windows-lockdown.reg`。

## 4.5 審查通過後

1. 在控制台的項目網址或「套件」頁找到**擴充功能 ID**（32 個英文字母），商店連結為
   `https://chromewebstore.google.com/detail/<ID>`
2. 在孩子的 Chrome（登入孩子帳號）：
   - 先到 `chrome://extensions` **移除開發模式載入的版本**（ID 不同，兩個同時存在會重複封鎖與通知），然後關閉開發人員模式。
   - 用商店連結安裝正式版。正式版的 ID 不同，**家長密碼、白名單、通知設定需要重新設定一次**。
3. 把 ID 填入 `policies/windows-lockdown.reg`，在家裡電腦以系統管理員身分匯入（讓孩子無法停用）。
4. 之後改版：調高 `manifest.json` 的 `version` → 重新打包 → 控制台「套件」分頁上傳新版 → 提交審查。審查通過後孩子的電腦會自動更新，設定保留。

## 5. 驗證跨電腦同步

1. A 電腦：Chrome 登入孩子帳號 → 開啟同步 → 從商店安裝 → 設定密碼、白名單，並啟用「白名單管理」
2. B 電腦：Chrome 登入孩子帳號 → 開啟同步 → 等待數分鐘，擴充功能會自動安裝
3. 在 B 電腦開啟非白名單網站，應顯示封鎖頁
4. 在 A 電腦新增一個網站，B 電腦數分鐘內即可開啟該網站
