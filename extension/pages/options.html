孩童安心上網管理平台

家長設定頁。所有設定會透過孩子的 Chrome 帳號同步到每一台電腦。

第一次使用：設定家長密碼

如果您已經在其他電腦設定過，請不要在這裡重設：確認孩子已登入 Chrome 並開啟同步， 等待設定自動同步下來（通常數十秒到數分鐘），這個頁面會自動更新。

請輸入家長密碼

白名單管理

只允許孩子開啟白名單內的網站，其他網站顯示封鎖頁；可選擇在封鎖時通知家長。

允許的網站（白名單）

輸入網域或直接貼上網址，例如 youtube.com。加入後其所有子網域（如 m.youtube.com）也會允許。可一次貼上多行。停用白名單管理時也可以先編輯名單。

    提示：有些網站需要多個網域才能正常運作（例如影片、登入頁面），若孩子回報畫面被擋，可在封鎖頁面上用家長密碼直接放行。

    開啟非白名單網站通知

    同一網域 60 秒內只通知一次。

    網站瀏覽通知

    孩子瀏覽任何網站時都通知家長，不會封鎖網站。適合第一階段「先觀察」，了解孩子常去哪些網站後再建立白名單。

    網頁載入完成時通知；同一網域 5 分鐘內只通知一次。被白名單管理封鎖的網站不會重複發送瀏覽通知。

    上網摘要報告

    記錄孩子在每個網站實際停留的時間，每天晚上與每週把摘要送到家長指定的 API（例如 Webex），不會封鎖網站。

    只計算 Chrome 在前景、孩子正在使用時的作用中分頁；閒置 2 分鐘後停止計時，但正在播放聲音的分頁（例如看影片）會繼續計時，螢幕鎖定時一律停止。 每台電腦各自記錄、各自送出報告（報告上會標示電腦名稱）；這段期間沒有上網紀錄時不送出。電腦在排定時間沒開機的話，下次開機會補送最近一份。

    寄送時間

    寄出前一天（0:00–24:00）的摘要
    寄出前 7 天的摘要（含每日上網時間）

    通知工具

    報告內容（{{report}} 的組成）

    報告由下列區塊由上到下組成，區塊之間空一行。可以開關、調整順序、修改文字，或新增自己的文字區塊；右邊的預覽會即時更新。 文字區塊可以按 Enter（或輸入 \n）換行，空一行為分段；支援 **粗體**、*斜體*、[連結](https://…)，會依下方選擇的通知工具自動轉換格式。

    可用的變數
    • 所有區塊：{{period}} 每日 / 每週、{{range}} 統計日期、{{email}} 孩子的帳號、{{device}} 電腦名稱、{{totalTime}} 總上網時間、{{siteCount}} 網站數
    • 排行的每一列：{{rank}} 名次、{{host}} 網站、{{time}} 停留時間、{{percent}} 百分比
    • 排行的「其他」列：{{count}} 其他網站數、{{time}} 其他網站合計時間
    • 每日上網時間的每一列：{{date}} 日期、{{time}} 當天上網時間
    • 每列以 1. 開頭會顯示成編號清單，以 - 開頭會顯示成項目清單。

      通知工具說明
      
      
      
        每個管理功能可以選擇不同的通知工具（Webex、Slack、Telegram、LINE、Discord），訊息格式會依工具自動調整，只需要填入網址或權杖；
        點選「如何申請？」可以看到各工具的申請步驟。選擇「自訂 API」時可以自行設定 Method / URL / Payload：
        URL 中的變數會自動做網址編碼，Payload 中的變數會自動做 JSON 跳脫；Payload 是合法 JSON 時以 application/json 送出，
        否則以純文字送出；Method 為 GET 時不送 Payload。
