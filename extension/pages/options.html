孩童安心上網管理平台

家長設定頁。所有設定會透過孩子的 Chrome 帳號同步到每一台電腦。

第一次使用：設定家長密碼

如果您已經在其他電腦設定過，請不要在這裡重設：確認孩子已登入 Chrome 並開啟同步， 等待設定自動同步下來（通常數十秒到數分鐘），這個頁面會自動更新。

請輸入家長密碼

管理功能 1

白名單管理

只允許孩子開啟白名單內的網站，其他網站顯示封鎖頁；可選擇在封鎖時通知家長。

允許的網站（白名單）

輸入網域或直接貼上網址，例如 youtube.com。加入後其所有子網域（如 m.youtube.com）也會允許。可一次貼上多行。停用白名單管理時也可以先編輯名單。

    提示：有些網站需要多個網域才能正常運作（例如影片、登入頁面），若孩子回報畫面被擋，可在封鎖頁面上用家長密碼直接放行。

    開啟非白名單網站通知

    同一網域 60 秒內只通知一次。

    可用變數：{{email}} 孩子登入 Chrome 的帳號、{{url}} 被擋的網址、 {{host}} 網域、{{time}} ISO 時間、{{localTime}} 本地時間、 {{timestamp}} 毫秒時間戳。

    管理功能 2

    網站瀏覽通知

    孩子瀏覽任何網站時都通知家長，不會封鎖網站。適合第一階段「先觀察」，了解孩子常去哪些網站後再建立白名單。

    網頁載入完成時通知；同一網域 5 分鐘內只通知一次。被白名單管理封鎖的網站不會重複發送瀏覽通知。

    可用變數：{{email}} 孩子登入 Chrome 的帳號、{{title}} 網頁標題、 {{url}} 網址、{{host}} 網域、{{time}} ISO 時間、 {{localTime}} 本地時間、{{timestamp}} 毫秒時間戳。

    API 格式說明

    URL 中的變數會自動做網址編碼，Payload 中的變數會自動做 JSON 跳脫。Payload 是合法 JSON 時以 application/json 送出，否則以純文字送出；Method 為 GET 時不送 Payload。

    跨電腦同步說明

    1. 在孩子使用的每台電腦，讓孩子的 Google 帳號登入 Chrome，並開啟「同步」（至少勾選「擴充功能」）。
    2. 在任何一台電腦安裝本擴充功能並設定好後，Chrome 會自動在其他電腦安裝本擴充功能，並同步所有設定。
    3. 修改設定後，其他電腦通常在幾分鐘內自動套用。
